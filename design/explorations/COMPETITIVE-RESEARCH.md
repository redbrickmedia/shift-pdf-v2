# Display-ad PDF competitor research

**Ticket:** [ST-14683](https://redbrickmedia.atlassian.net/browse/ST-14683)  
**Reviewed:** 2026-08-19  
**Audience:** product, design, engineering

## Method

This is the working competitor set for the display-ad entry path at
`app.shift.com/pdf/1`. It focuses on products that advertise the same high-intent
jobs: convert, compress, merge, edit, and sign.

Claims and limits below were checked against each vendor's official product,
pricing, security, or help pages. Google Ads Transparency Center does not provide
stable public URLs for commercial creatives, so ad presence and current creative
copy should be rechecked there before a campaign review. The durable evidence in
this document is the landing-page promise and the product reality behind it.

## Competitor set

### Smallpdf

**Public promise**

- "30 tools to convert, compress, and edit PDFs for free."
- A simple, polished all-in-one document workflow.
- Strong trust signals: one billion users, ISO/IEC 27001, GDPR/CCPA compliance,
  TLS encryption, integrations, mobile apps, and 24/7 support.

**Product reality**

- The free plan has limited document downloads and daily limits across many
  tools.
- Strong compression, OCR, text editing, batch work, and unlimited downloads
  require Pro.
- Files for most free tools are uploaded to Smallpdf and deleted after one hour.
  Stored account files and e-signature workflows have different retention.

**What works**

- Excellent hierarchy and plain-language job labels.
- Familiar, low-friction upload surfaces.
- Mature security proof and social proof.

**Opening for Shift**

- Make "free" literal: no account, trial, daily quota, or surprise download gate.
- Make local processing visible before upload, not buried in a security page.
- Match the polished entry experience without turning the result into an upsell.

### iLovePDF

**Public promise**

- "Every tool you need to work with PDFs in one place."
- Tools are "100% FREE and easy to use."
- Broad coverage, including workflows, forms, OCR, signatures, AI features, and
  desktop/mobile apps.

**Product reality**

- The free Basic plan has limited tools and limited document processing.
- Common operations have file-count and file-size caps; Premium removes ads and
  unlocks unlimited processing.
- Web files are processed on iLovePDF servers and normally deleted within two
  hours. Signed documents can be retained longer for legal reasons.

**What works**

- The tool grid communicates breadth immediately.
- Categories map cleanly to user intent.
- Premium value is easy to understand.

**Opening for Shift**

- Keep the same breadth while reducing grid overload with search, pinned primary
  jobs, and remembered recent tools.
- State local processing and no limits beside the first action.
- Avoid ad clutter and premium ambiguity.

### PDF24 Tools

**Public promise**

- Free, easy-to-use tools for nearly every PDF problem.
- No artificial limits and no installation.
- Online and offline options.

**Product reality**

- Online tools upload files to PDF24 servers and remove them after a short time.
- The service is funded by advertising.
- Local processing requires the separate PDF24 Creator desktop product.

**What works**

- Strong breadth and a credible no-limit promise.
- Direct explanations of online versus offline processing.
- Utility-first positioning.

**Opening for Shift**

- Offer broad, no-limit tools without display ads.
- Process locally in the same browser experience rather than sending users to a
  separate desktop app.
- Use a calmer, more polished information architecture.

### Sejda

**Public promise**

- An "easy, pleasant and productive PDF editor."
- More than 30 task-focused web tools.
- A desktop option with the same features and local processing.

**Product reality**

- Web files are uploaded and processed on Sejda servers, then deleted after two
  hours.
- Free web use is limited to three tasks per hour, 50 MB, and 200 pages.
- Desktop free use is limited to three tasks per day; unlimited use is paid.

**What works**

- Clear distinction between web and local processing.
- Strong editor positioning and detailed task flows.
- The tool pages explain limits before the user commits.

**Opening for Shift**

- Deliver local processing in the web tool with no install handoff.
- Keep limits out of the happy path.
- Preserve Sejda's task clarity while making navigation and returning to a
  recent job faster.

### Adobe Acrobat Online

**Public promise**

- More than 25 PDF and e-signature tools from "the inventor of the PDF."
- Speed, accuracy, reliability, and high-fidelity editing.
- Free online conversion, compression, editing, filling, and signing.

**Product reality**

- Free use is limited; some downloads, advanced editing, batch work, storage, or
  unlimited operations require sign-in, a trial, or a paid Acrobat plan.
- Online operations upload the file to Adobe services.
- Adobe's account and cloud-storage ecosystem is a strength for continuity, but
  it adds identity and storage decisions to a quick task.

**What works**

- Unmatched authority and trust in document fidelity.
- Polished tool pages with strong expectations.
- A credible cross-device document ecosystem.

**Opening for Shift**

- Win on speed to first result for lightweight jobs.
- Explain local privacy in one sentence and require no account.
- Be honest about formats whose fidelity is not yet comparable to Acrobat.

## Claims-versus-product summary

| Competitor | Landing-page promise            | Constraint behind the promise            | Strongest trust cue                        |
| ---------- | ------------------------------- | ---------------------------------------- | ------------------------------------------ |
| Smallpdf   | 30 free, simple tools           | Daily/download limits; server upload     | Certifications and scale                   |
| iLovePDF   | Every tool, 100% free           | Processing/file caps; ads; server upload | Breadth and user volume                    |
| PDF24      | Free with no artificial limits  | Ad-funded; server processing online      | Direct online/offline explanation          |
| Sejda      | Pleasant editor and 30+ tools   | Hourly/daily, size, and page limits      | Explicit deletion and desktop-local option |
| Adobe      | 25+ tools from the PDF inventor | Sign-in and paid gates; cloud processing | Brand authority and fidelity               |

## Repeated market gaps

1. **"Free" is conditional.** Limits, sign-in, trials, ads, or paid-only quality
   often appear after intent is established.
2. **Privacy is remote.** Vendors publish meaningful security details, but the
   processing model is rarely the first thing a user sees.
3. **Breadth creates overload.** Large grids prove capability but make the next
   action harder to scan.
4. **Return value depends on accounts.** Cross-device continuity usually requires
   identity, cloud storage, or an installed desktop app.
5. **Trust and fidelity are uneven.** Adobe owns authority; smaller tools lean on
   simplicity, deletion promises, or review volume.
